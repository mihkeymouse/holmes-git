## The Gitventure of the Abbey Grange
**A Sherlock Holmes mystery played through Git.**
This is a git-driven, unabridged game adaptation of Arthur Conan Doyle's *The Adventure of Abbey Grange*.

Dr Watson has recorded the details of a remarkable incident in his version controlled casebook.

You, as Sherlock Holmes, must use the Git knowledge in your arsenal to solve the case. 

## Getting Started
Requires Python 3.12+ and Git.


```bash
git clone https://github.com/mihkeymouse/holmes-git.git
cd holmes-git
python scripts/build_case.py
```


This generates a playable Git repository.Publish it to Github with Actions enabled to begin the investigation
